# Noocoks — Portfolio técnico

Portfolio personal sobre desarrollo de software, sistemas, infraestructura y ciberseguridad.

## Proyectos destacados

- **[Libreta](https://github.com/Noocoks/Libreta)** — base de conocimiento técnica sobre ciberseguridad, Android, IA, desarrollo y laboratorios. Sitio: https://noocoks.github.io/Libreta/
- **[SOUNWD](https://github.com/Noocoks/SOUNWD)** — aplicación para escritorio Windows/Linux y versión Android en desarrollo, con interfaz gráfica basada en Python/Kivy y yt-dlp.
- **[OLV — Open Live Video](https://github.com/Noocoks/OpenLiveVideo)** — aplicación local para preparar y producir vídeos verticales con Python, FFmpeg, narración, subtítulos y clips de vídeo.

El laboratorio personal incluye experimentación con Docker, Prometheus, Grafana, servicios autoalojados, virtualización y redes. También se documenta Dualvers V2, un cliente CLI local multi proveedor.

## Perfil técnico

Formación en Desarrollo de Aplicaciones Web (DAW), con experiencia práctica en desarrollo web durante las prácticas en InforCopy.

Áreas de interés y trabajo:
- Desarrollo web: HTML, CSS, JavaScript.
- Programación y aplicaciones: Python, Kivy, SQL, PHP.
- Sistemas y despliegue: Windows, Linux, Docker, Apache y GitHub Actions.
- Ciberseguridad: OSINT, reconocimiento, documentación técnica y laboratorios autorizados.
- Observabilidad: Prometheus y Grafana.
- IA y automatización: Ollama, APIs de OpenAI y Anthropic.

Las tecnologías reflejan formación, proyectos y experimentación; no son certificaciones ni una escala de dominio.

## Publicación con GitHub Pages

1. Abre **Settings → Pages**.
2. Selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/ (root)`.
4. Guarda los cambios y espera a que termine el despliegue.
